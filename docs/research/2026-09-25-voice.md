# Voice assistants, shopping list and Spotify

> Research for the earlier Home Assistant plan (superseded by the web app on 25 Sep 2026). Kept for reference; many facts still apply.

**Area:** voice

## Recommendation

Keep GEMINI as the tablet's default digital assistant. Google Assistant on Android phones and tablets began shutting down on 4 Sep 2026 and cannot be switched back, so 'Hey Google' now means Gemini. Only one app can be the default assistant, and only that app gets a wake word. Gemini is the only option that gives a Google-centric UK household hands-free 'Hey Google', the shared Google Keep shopping list (the same list Gemini-for-Home Nest speakers and phones write to) and 'play X on Spotify'. SHOPPING LIST: use ONE Google Keep list titled exactly 'Shopping list', shared with the household. Say 'Hey Google, add milk to my shopping list'. The dashboard's 'Shopping list' button launches Keep (app://com.google.android.keep). If you want the list shown on the dashboard, add the unofficial HACS 'Google Keep Sync' integration (todo.google_keep_shopping_list). It is two-way, but changes made in Keep only reach HA on a poll (15 min by default). Do NOT pick Bring!/AnyList/HA-local lists if you want Gemini voice: Google removed third-party list providers in June 2023 and Gemini only writes to Keep (or OEM notes apps). SPOTIFY: connect Spotify in Gemini's connected apps. Say 'Hey Google, play <artist> on Spotify' (English only; Premium needed to play a specific song). The button is app://com.spotify.music. CLAUDE: there is no official voice-mode deep link, shortcut, tile or wake word. The documented claude:// scheme only covers Claude Code routes, and the Claude widget's mic button is dictation, not voice mode. Best button: an intent: URL that starts the Claude app's exported assistant overlay (com.anthropic.claude/.mainactivity.AssistantOverlayActivity, action VOICE_ASSIST). This comes from a decompiled manifest and has not been tested on a device. If it does not open straight into voice, fall back to app://com.anthropic.claude and tap the sound-wave icon. By voice: 'Hey Google, open Claude' should open the app, not voice mode. This follows Gemini's generic 'open <app>' ability and has not been tested for Claude. The Claude app CAN be set as the default digital assistant: its manifest has a VoiceInteractionService, and Android Police and a YouTube tutorial confirm it. But doing that kills 'Hey Google', gives no wake word, and the role reportedly resets after Claude app updates. Not recommended for a shared wall panel. GEMINI BUTTON: intent:#Intent;action=android.intent.action.VOICE_ASSIST;package=com.google.android.googlequicksearchbox;launchFlags=0x10000000;end (resolves to GoogleAppVoiceAssistEntrypoint). Fallback: app://com.google.android.apps.bard. HOME BUTTON: intent:#Intent;action=android.intent.action.MAIN;category=android.intent.category.HOME;launchFlags=0x10000000;end. These app:// and intent: URLs work natively from dashboard buttons inside the HA Companion app (verified in its source code). In Fully Kiosk, use fully_kiosk.start_application (package only) or intent: URLs (community pattern). OPTIONAL 'Claude answers by voice inside HA': add the official Anthropic integration (needs a separate pay-as-you-go API key, not the Claude.ai subscription) as the conversation agent of an Assist pipeline. Put a dashboard button with tap_action: assist + start_listening: true on the tablet. This keeps Gemini as the default assistant. A hands-free HA wake word ('Hey Nabu/Jarvis/Mycroft', on-device microWakeWord, Companion app 2026.2.3+, experimental) exists, but only if HA becomes the default assistant, which again removes 'Hey Google'.

## Facts

- Google began removing Google Assistant from Android phones AND tablets on 4 Sep 2026. Rollout takes 'a few weeks', and afterwards users cannot switch back. Gemini replaces it. Low-end devices (Android Go / below the Gemini minimum) reportedly keep a legacy Assistant. _(source: https://9to5google.com/2026/08/04/google-assistant-september-2026-shutdown/ ; https://chromeunboxed.com/its-official-gemini-will-completely-replace-the-google-assistant-on-phones-next-month/ ; https://searchengineland.com/google-assistant-to-be-discontinued-on-android-starting-september-4-484307)_ **[yes - secondary/third-party source]**
- Gemini app minimum: Android 10+ and 2 GB+ RAM. Lenovo Tab M10 variants run Android 10-14 (M10 Plus Gen 3 got Android 13; only the M10 5G was slated for Android 14), so most M10s qualify, but check the exact model and RAM. _(source: https://www.android.com/intl/en_uk/articles/gemini-android-app/ ; https://support.google.com/gemini/answer/14579026 ; https://mynexttablet.com/lenovo-android-14-update/)_ **[yes - secondary/third-party source]**
- 'Hey Google' starts Gemini hands-free once 'Hey Google' and Voice Match are on (Gemini > Settings > 'Talk to Gemini hands-free'). With 'Gemini on lock screen' enabled it also works while locked, but personal content (Calendar, Keep) may ask you to unlock. Pixel Tablet is a documented exception: when locked it uses Assistant. _(source: https://support.google.com/gemini/answer/14576209?hl=en ; https://support.google.com/gemini/answer/14554984?hl=en&co=GENIE.Platform%3DAndroid (via search snippets; support.google.com blocked for direct fetch))_ **[yes - secondary/third-party source]**
- Whether 'Hey Google' is detected with the SCREEN OFF on a Lenovo Tab M10 depends on low-power hotword (DSP) hardware and is not documented. Users of other devices report the screen dimming or turning off mid-request. _(source: https://us.community.samsung.com/t5/Galaxy-S25/Hey-Google-Gemini-not-working-when-the-screen-is-off/td-p/3548817)_ **[no - UNVERIFIED]**
- Only the current default digital-assistant app gets the always-on wake word. Third-party assistants (ChatGPT, Claude) set as default cannot use a hotword, because Google keeps the privileged hotword APIs for preinstalled apps. Switching the default away from Gemini therefore loses 'Hey Google'. _(source: https://www.tomsguide.com/ai/chatgpt/how-to-make-chatgpt-your-default-assistant-on-android-instead-of-gemini ; HA docs note: https://github.com/home-assistant/home-assistant.io/blob/current/source/voice_control/android.markdown)_ **[yes - secondary/third-party source]**
- The EU DMA decision of 16 Jul 2026 obliges Google to open Android invocation features, including wake words, to rival assistants by 1 Aug 2027 (Android 18). Concurrent multiple wake words are due by 1 Aug 2028. It is an EU measure: the UK is not covered automatically. _(source: https://ec.europa.eu/commission/presscorner/detail/en/ip_26_1634 ; https://digital-markets-act.ec.europa.eu/commission-provides-guidance-google-ai-interoperability-android-and-sharing-google-search-data-under-2026-07-16_en)_ **[yes - secondary/third-party source]**
- Assistant shopping lists were migrated into Google Keep from late 2023. Gemini can create lists, show them and add items to existing Google Keep lists ('Add X to my <name> list'; add '@Google Keep' to force Keep). This needs Keep Activity / Gemini Apps Activity on. Supported notes backends are Keep plus some OEM notes apps. Lenovo Notes is supported only on Lenovo Yoga Tab Plus, so a Tab M10 uses Keep. _(source: https://support.google.com/assistant/answer/14171370?hl=en ; https://support.google.com/gemini/answer/15230597?hl=en&co=GENIE.Platform%3DAndroid (search snippets))_ **[yes - secondary/third-party source]**
- Third-party notes/list providers (AnyList, Bring!, Any.do) were removed from Google Assistant on 20 Jun 2023, and Gemini does not list them. Voice items from Gemini or Nest speakers cannot go straight into Bring!/AnyList. _(source: search summary of https://support.google.com/gemini/answer/15230597 and third-party reporting)_ **[partial]**
- Gemini for Home on Nest speakers/displays adds to the Google Keep shopping list, and is available in the UK in 2026 (the Google Home Speaker launched in the UK at £99.99). An Aug 2026 bug broke Home/Gemini to Keep list additions. Google said the fix was deployed by ~28 Aug 2026. _(source: https://www.techadvisor.com/article/3110206/gemini-for-google-home-launches-in-16-new-countries.html ; https://9to5google.com/2026/08/25/google-home-keep-integration-broken-due-to-bug/ ; https://www.androidauthority.com/google-home-keep-lists-glitch-3704554/)_ **[yes - secondary/third-party source]**
- The Google Keep Android app supports a 'Single note' home-screen widget with tickable checklists. Keep web links have the form https://keep.google.com/#NOTE/<id> (or #LIST/<id>). Whether the Keep Android app intercepts these links has not been confirmed. _(source: https://support.google.com/keep/answer/13302793?hl=en ; https://notes.joeldare.com/linking-google-keep-notes)_ **[partial]**
- HACS 'Google Keep Sync' (domain google_keep_sync, v1.1.0, last commit 20 Apr 2026, gkeepapi 0.17.1 + gpsoauth). It is unofficial and needs a Google master token ('aas_et/...') or OAuth token. Entity id = todo.google_keep_<slugified list title>, e.g. todo.google_keep_shopping_list. HA to Keep is pushed immediately; Keep to HA is polled every 15 min by default. Extra action: google_keep_sync.request_sync. _(source: https://github.com/watkins-matt/home-assistant-google-keep-sync (README, manifest.json, custom_components/google_keep_sync/todo.py))_ **[yes - primary source]**
- HA-native lists by voice: the built-in intents HassShoppingListAddItem ('add {item} to [my|the] [shopping] list', shopping_list integration -> todo.shopping_list) and HassListAddItem ('add {item} to [my|the] {name} [list]', any exposed todo entity) work with Assist. Bring! is an official integration (polls every 90 s, supports Assist). Google Tasks is official (polls every 30 min). AnyList is HACS-only and needs a companion add-on. _(source: https://github.com/home-assistant/intents/tree/main/sentences/en ; https://www.home-assistant.io/integrations/bring/ ; https://www.home-assistant.io/integrations/google_tasks/ ; https://github.com/kevdliu/hacs-anylist)_ **[yes - primary source]**
- Gemini plus Spotify: link Spotify to the Google account in Gemini's connected apps (formerly extensions). Android only, and the Gemini language must be English. A specific song needs Spotify Premium. If several media apps are connected and none is named, Gemini uses the last one used. Say '... on Spotify' or '@Spotify' to force it. _(source: https://support.google.com/gemini/answer/15300097?hl=en&co=GENIE.Platform%3DAndroid (search snippets) ; https://9to5google.com/2024/11/26/spotify-gemini-extension/)_ **[yes - secondary/third-party source]**
- Gemini on Android can open installed apps by voice ('Hey Google, open <app>'). Saying 'open Claude' should open the Claude app's main screen, not voice mode. This has not been tested specifically for Claude. _(source: https://support.google.com/gemini/answer/14579631?hl=en&co=GENIE.Platform%3DAndroid (search snippets))_ **[partial]**
- Claude voice mode is available on all plans on Android and is started by tapping the sound-wave icon in the chat input. It supports push-to-talk, voice/pace selection and connected tools. Dictation (the mic icon) is a different feature: speech becomes text and replies are text. _(source: https://support.claude.com/en/articles/11101966-use-voice-mode ; https://support.claude.com/en/articles/10065434-use-dictation-on-claude-mobile)_ **[yes - primary source]**
- The Claude Android home-screen widget has three buttons: chat, camera and microphone. Anthropic's help centre calls the microphone 'voice dictation' (new chat plus dictation), NOT voice mode. The help centre documents no Android Quick Settings tile, lock-screen access or voice-mode shortcut. Those (Lock Screen, Control Center, Action button) are documented for iOS 18+ only. _(source: https://support.claude.com/en/articles/10534883-use-the-claude-widget-on-android ; https://support.claude.com/en/articles/10302511-access-claude-for-ios-on-your-lock-screen-control-center-and-action-button)_ **[yes - primary source]**
- The only DOCUMENTED Claude mobile URL scheme is for Claude Code: claude://code, claude://code/{session-id}, claude://code/new?q|prompt=&mode=plan|code&repo=owner/name&branch= (plus https://claude.ai/code/... universal links). There is no documented voice-mode or chat-prefill link, and the old claude.ai/new?q= prefill reportedly no longer works. _(source: https://support.claude.com/en/articles/14898120-open-the-claude-mobile-app-with-a-link)_ **[yes - primary source]**
- A decompiled Claude Android manifest (v1.260430.10, Apr 2026) shows several things. MainActivity is the launcher. com.anthropic.claude.mainactivity.AssistantOverlayActivity is exported and handles android.intent.action.ASSIST and VOICE_ASSIST. The services ClaudeVoiceInteractionService (android.service.voice.VoiceInteractionService) and ClaudeRecognitionService let it be chosen as the default digital assistant. DeepLinkActivity handles the claude:// scheme (any host) and https://claude.ai app links (/new, /chat, /project/, /code, /dispatch, /share, /artifacts...). Two app widgets (ClaudeAppWidgetReceiver, OrbitAppWidgetReceiver). NO static app shortcuts and NO TileService (so no Quick Settings tile). minSdk 29. _(source: https://github.com/GitBubble/claude-coca/blob/main/design/phase0/decompiled-resources/resources/AndroidManifest.xml (third-party decompilation))_ **[yes - secondary/third-party source]**

SwitchAI launches com.anthropic.claude.mainactivity.AssistantOverlayActivity as Claude's 'voice input' entry point (changed from MainActivity on 26 Feb 2026). That suggests, but does not prove, that the overlay opens in voice. _(source: https://github.com/WSTxda/SwitchAI/blob/main/app/src/main/java/com/wstxda/switchai/assistant/ClaudeAssistant.kt (commit 463b31c) ; https://github.com/JishnuPG-tech/Hermes-x/blob/main/docs/claude-android-reverse-engineered/00_OVERVIEW_AND_SYSTEM_TOPOLOGY.md)_ **[partial]**

Anthropic's help centre does not document this. _(source: https://www.androidpolice.com/switched-from-gemini-to-claude-for-month-on-android-have-clear-verdict/ (May 2026) ; https://www.youtube.com/watch?v=iXfhh4CBIiA (Mar 2026) ; https://github.com/anthropics/claude-code/issues/41696)_ **[yes - secondary/third-party source]**

## Gotchas

- Only ONE default digital assistant app. Gemini = 'Hey Google'. Claude = overlay via gesture/long-press, with NO wake word. HA Companion = software wake word ('Hey Nabu/Jarvis/Mycroft'). Choosing Claude or HA as default disables 'Hey Google' on the tablet.
- There is no official Claude voice-mode deep link, static shortcut, Quick Settings tile or wake word on Android. The widget mic is dictation (reply in text), not voice mode. The claude:// scheme is documented only for Claude Code routes.
- The Claude AssistantOverlayActivity intent comes from a decompiled manifest. Activity names can change in any app update, and it is untested whether an explicit launch works when Claude is NOT the default assistant, or whether it opens full voice mode rather than a text/dictation overlay.
- If Claude is set as default assistant, the role reportedly gets cleared after Claude app updates (GitHub issue #41696). A wall panel would silently lose it.
- Tablet gesture: on the Lenovo M10, long-press POWER may open the power menu rather than the assistant. Use the swipe-up-from-bottom-corner gesture (gesture nav) or long-press Home (3-button nav). Not verified on Lenovo's builds.
- Screen-off 'Hey Google' on budget Lenovo tablets is unconfirmed. Keep the screen on (Fully Kiosk dimmed screensaver or Companion 'Keep screen on') rather than letting it sleep. Set Screen lock = None so Gemini can read personal content (Calendar/Keep) without asking to unlock.
- Gemini chooses the Keep note by name. Keep exactly ONE list titled 'Shopping list' (shared with household Google accounts), or Gemini may create or append to the wrong note. '@Google Keep' in the prompt forces Keep. Needs Keep Activity / Gemini Apps Activity ON.
- The Keep voice path has been fragile: an Aug 2026 Google Home/Gemini-for-Home bug stopped 'add X to my shopping list' until Google fixed it around 28 Aug 2026.
- Bring!/AnyList/HA-local lists cannot be fed by 'Hey Google' (Google removed third-party list providers in June 2023). Mixing them splits the household list.
- Google Keep Sync (HACS) uses the unofficial gkeepapi with a master token. It may break with Google changes. Keep-to-HA updates poll every 15 min by default, and edits in HA overwrite Keep on conflict. Google Tasks (official) polls every 30 min and is not where Gemini puts 'shopping list' items.
- Do not try to embed keep.google.com in Fully Kiosk/WebView: Google blocks sign-in in embedded WebViews. Launch the Keep app instead. Whether Keep opens a specific note from a keep.google.com/#LIST/<id> link is UNVERIFIED.
- Spotify via Gemini needs a Spotify Premium account to play a specific song. It is English-language only, and plays on the tablet's own small speaker unless you cast.
- The HA Anthropic integration bills per token on a separate Anthropic API account (not the Claude.ai Pro/Max subscription). The spoken voice is HA's TTS (HA Cloud or Piper), not Claude app voice mode. Speech-to-text also needs HA Cloud or local Whisper.
- HA dashboard Assist mic: native in the Companion app, but in Fully Kiosk (a WebView) the browser blocks the mic unless HA is served over HTTPS.
- HA Companion command_activity/command_launch_app require the 'Display over other apps' permission (prompted on first use), because of Android background-activity-start limits.
- If Fully Kiosk kiosk mode is locked, launched apps must be whitelisted (Gemini/Google app, Keep, Spotify, Claude, HA). Avoid Fully features that hold the microphone (acoustic detection), which may clash with hotword listening. UNVERIFIED specifics.
- HA Companion wake word is experimental and keeps the CPU awake. Acceptable on a mains-powered wall tablet, but the docs advise turning it off if the app becomes unresponsive.
- The EU DMA wake-word opening (by Aug 2027/2028) is an EU measure. A UK tablet may not benefit.

## Setup steps

- Tell us the exact tablet model (e.g. TB-X606F / TB328FU / TB125FU), Android version and RAM. Gemini needs Android 10+ and 2 GB RAM or more.
- On the tablet: update the Google app and install/update Gemini. Settings > Apps > Default apps > Digital assistant app = Google/Gemini. In Gemini > Settings, turn on 'Hey Google' + Voice Match (train your voice, and add other household voices) and 'Gemini on lock screen'. Set Screen lock = None.

In Gemini connected apps, make sure Google Keep is enabled and Keep Activity is on. - Spotify: install Spotify and sign in (Premium recommended). In Gemini > Settings > Apps, connect Spotify. Test 'Hey Google, play Coldplay on Spotify'.
- Claude: install 'Claude by Anthropic' and sign in. Test voice mode (sound-wave icon). Test 'Hey Google, open Claude'.
